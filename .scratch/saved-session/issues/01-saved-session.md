# Save a session on the Membership manager's PC

Type: task
Status: needs-triage

## Idea

The first version leaves no data behind: closing the tab wipes everything. A later version could let the Membership manager save a session (the loaded exports and/or the comparison result) in the browser's local storage, so they can pick up where they left off.

Requirement: before the Membership manager leaves, the tool clearly shows what personal data is left behind on the PC and how to remove it.

Raised while grilling [first-version 05](../../first-version/issues/05-how-to-run.md).
